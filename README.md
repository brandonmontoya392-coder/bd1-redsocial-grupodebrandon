## Descripción del proyecto

La Red Social Pascualina es una propuesta de plataforma orientada a facilitar la comunicación y la interacción entre estudiantes. El sistema busca crear un espacio donde los estudiantes puedan compartir información sobre sus intereses, habilidades y áreas de estudio, además de conectarse con otros compañeros.

La plataforma permitirá realizar diferentes actividades, como crear perfiles, seguir a otros estudiantes, establecer conexiones de mentoría, realizar publicaciones, participar en grupos y organizar eventos académicos o sociales.

Para esta primera tarea se desarrolla el modelo conceptual de la base de datos mediante un Modelo Entidad-Relación (MER), identificando las principales entidades, atributos, relaciones y cardinalidades necesarias para representar el funcionamiento de la plataforma.
